自 v0.16.0 以来 **190 个提交**（0.17.x 为内部迭代线，未单独发版）。这个版本把 HaoAI 从「能用的聊天 Agent」推进到「编排层成熟的后台自动化 Agent」。核心三件事：**后台任务可观测性、Agent 引擎成体系、真机可用性**。

## 🆕 后台任务可观测性（编排层，本次主打）

- **任务悬浮窗**：任务运行中切到其他应用，屏幕上方出现悬浮胶囊——实时滚动当前步骤（🟢 运行中 / 🟠 等待审批 / ⚪ 已结束），内置停止键；点按展开完整任务卡（目标、步骤流、任务清单进度、已运行时长、去处理），可拖动、位置记忆。回到 HaoAI 自动隐藏，任务结束停留 3.5 秒后自退。
- **动态任务卡通知**：以前是一成不变的「任务将在后台继续执行」，现在标题=任务目标、正文实时更新步骤流与「任务清单 N/M 完成」，运行中带「停止」按钮，等待审批时自动升级高优先级提醒。
- **假中断修复**：切窗口回来不再误报「任务已中断」，跨实例（任务真正在后台跑时）停止路由打通——任何时候都能停得下来。

## 🤖 Agent 引擎（E 系列成体系）

- **断点续跑**：进程被杀后回到 app 显示恢复横幅，确认后从断点接续目标
- **循环内插话**：任务运行中直接打字发送即插队注入，引擎在工具间隙消费（可撤回）
- **同轮多工具并行**：READ 类工具并发执行（并修复了并行浏览器死锁 ANR）
- **子代理逐路可观测**：spawn_agents 各路状态/token 用量实时聚合进工具卡
- **单轮成本熔断**：token 上限 / 工具圈数上限 / 70% 软提醒优雅收尾，分级开关
- **请求级重试 + Provider 降级链**：主服务失败自动切备用
- **open_uri 直达导航**：「打开某页面」类任务一步直达系统界面（设置面板/应用组件/intent），对齐 上游「API 优先于视觉循环」的行动模型，不再傻傻截图循环
- **工具分层注入**：core / extended / mcp 三档按需加载（`tools_enable`），上下文更省
- **Plan/Execute 模式**、文件变更 `/undo` 回滚 + 工具卡回滚、技能自改进闭环
- **工作流引擎**：JSON 定义、四类触发、审批门控、步骤间数据传递、条件分支、外部广播触发、可视化步骤编辑器
- **端侧推理三后端**：CPU / GPU / NPU（骁龙 8 Gen 2 Hexagon）一版通吃
- **修深层 bug**：`config_set` 工具 schema 违反 JSON Schema 规范（items 写成数组），GLM 系网关严格校验直接 400——宽容网关掩盖已久，本次根治

## 🧰 工具与沙箱

- **Linux 沙箱**：PRoot 双发行版（Ubuntu/Alpine）、bash 多后端（toybox/linux/ssh）、沙箱内长任务（后台投递 + `job_output` 查看）、MCP stdio 联动
- **内置浏览器**：WebView 工具组 + 两段式预览面板（35%~88% 拖拽调高）
- **虚拟屏自动化**：VScreen 虚拟屏 + 8 工具、实时预览面板、WMS 强制取帧真机跑通、Shizuku/root 三级上屏通道
- **设备工具包**：剪贴板 / 日历 / 联系人 / OCR / 闹钟 / 通知读取
- **MCP**：Streamable HTTP + stdio 双通道、headers Keystore 加密、自定义 header 默认掩码
- **安全加固**：apiKey 明文落盘泄漏口全堵（拒绝路径+快照脱敏）、`job_output` 路径穿越校验、技能隔离晋升（候选态→人工验证才进索引）+ 疗效遥测（连续失败自愈出索引）
