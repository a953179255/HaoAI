导入 SKILL.md（与手机端同一形状）
一个目录一份 SKILL.md，YAML 头里写 name / description。 装进 HAOAI_HOME/skills，和手写的 /命令 一起出现在输入框的 / 菜单里。 这一版是"你唤起"：不注入系统提示，模型也不会自己去翻。

跑完自动执行（钩子）
一轮跑完后替你在这条会话的工作区里执行一段命令：记一笔日志、推个通知、把产物挪进目录。 结论全文在 $env:HAOAI_OUTFILE 指的那个文件里，会话 id 在 $env:HAOAI_SID。 命令只有你在这里能写（模型加不了自己的钩子）；跑失败只记在这条上，不会打断会话。

手机联动（局域网）
—
这一条改变的是这台电脑会不会替手机动手：勾上之后，手机上发一句话 就等于在电脑上按了发送。默认不勾；ask 档照样会逐条弹审批，所以"批"和"派"是分开的两个权限。
开着的时候这台 PC 会在局域网监听一个端口：手机配对后能只读看这几条会话， 并替你在手机上点"允许一次 / 拒绝"。密钥、工作区绝对路径、工具原始输出都不在这个通道里。 不在信得过的网络就别开。
到点自己起一条新会话去跑这句话（不搅乱你正在聊的那条）。 机器睡着时不补跑：醒来最多补一次，不会一口气跑八遍。
