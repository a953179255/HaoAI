---
name: 学习计划
description: 要在限定时间里学会一门技能或通过一门考试，需要一份能照着执行的计划表时使用。
---
1. 先定终点：写清目标、判断是否学会的标准与截止日期，再倒推出要覆盖的知识点。
2. 按每周真实可投入的时长切块，遵循当天学、次日复习、一周后回顾的节奏排课。
3. 给每周留一个可验收的产出：一道题、一页笔记，或一个能跑通的小例子。

产出格式：目标与验收标准 + 按周的计划表（周次 / 主题 / 任务 / 产出）+ 每周复盘的三个固定问题。

常见坑：
- 别按理想时长排满，至少留两成机动时间，否则一次加班就全盘作废。
- 别只排输入型任务，没有产出就无法检验到底学会没有。
