---
name: 日志排障
description: 程序报错或行为异常，需要从日志、堆栈与控制台输出里定位根因时使用这个技能。
---
1. 先复现问题并锁死时间窗，只取报错前后各 200 行日志，别一上来就通读整个文件。
2. 从最具体的错误行往回找第一条异常和它的堆栈，定位到出错的函数与当时输入。
3. 提出 2 到 3 个可能原因，逐个用最小复现验证，确认后再动手改。

产出格式：现象一句话 + 时间线（何时、做了什么、报了什么）+ 根因 + 修复步骤；确认不了的列成待验证项。

常见坑：
- 别只盯最后一行报错，真正的原因常常是最外层捕获时才露出来的。
- 没读完整堆栈就猜原因，会修掉一个症状、留下三个病灶。
