---
name: 批处理脚本
description: 需要在 Windows 上写 .bat 或 .cmd 脚本、把某个重复操作做成一键执行时使用。
---
1. 先定边界：脚本在哪个目录运行、要不要管理员权限、失败时怎么收场、会生成哪些文件。
2. 按骨架起手：`@echo off`、`setlocal`、`cd /d "%~dp0"` 定住工作目录，路径一律加引号。
3. 每步失败都要看得见，用 `errorlevel` 接住，末尾 `pause` 免得窗口一闪而过。

产出格式：完整可运行的 .bat 代码块，再配一段说明，写清怎么用、文件落在哪、怎么撤销。

常见坑：
- 路径含中文或空格必须加引号，存成 ANSI，或首行 `chcp 65001` 再存 UTF-8。
- `%` 与 `!` 在循环里含义不同，循环体取变量要用延迟展开。
