---
name: 表格排版
description: 要把并列信息整理成 markdown 表格，或修一个列错位、被换行撑破的表格时使用。
---
1. 先数清楚列数与每列内容，确定哪列是主键、哪几列是属性；超过 6 列就拆成两张表。
2. 用竖线与分隔行搭骨架，同一列保持同类内容：都是日期、都是数字，不要混着写。
3. 校对表头与空值：表头用名词，单元格写短语不写整句，缺失统一填 `-`。

产出格式：一句引导 + 规整的 markdown 表格 + 必要的表注（统计口径与截止日期）。

常见坑：
- 单元格里再出现竖线要转义成 `\|`，否则表格当场断列。
- 含换行的长句会把表格撑破，先压成短语或挪到表下说明。
