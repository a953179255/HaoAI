---
name: README 补写
description: 项目缺 README、或已有 README 过时残缺，需要补齐结构和真实用法时使用。
---
1. 先读代码与配置搞清事实：怎么安装、怎么跑起来、入口和依赖有哪些，拿不准的别写。
2. 按固定骨架补：一句话简介、快速开始、配置项说明、目录结构、常见问题五段。
3. 每条命令都亲自验证一遍，配置项对照代码里的真实字段名，别照着记忆写。

产出格式：完整 README 正文，按标题分段，快速开始段给出可直接粘贴的命令代码块。

常见坑：
- 别写“即将支持”这类没有依据的承诺，那会变成对使用者的欠账。
- 示例输出和路径要用当前版本的真实结果，过期示例比没有更误导。
